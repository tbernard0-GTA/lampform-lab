# v0.9 — experience only

Visual thesis: a quiet scientific exhibit, with sage physical geometry filling the canvas and one clear decision at a time.

Content plan: five story chapters; Design chooses a part, a question and a hypothesis before revealing comparison and interpretation; Test offers the four controlled samples; Advanced holds all existing engineering data.

Interaction thesis: crossfade between decisions, a synchronized before/after reveal of real solids, and thumbnail hover/focus that makes the chosen experiment tangible. Reduced-motion users receive immediate state changes.

The v0.8 solver, computed catalogue, metrics and STL bytes are frozen. This release changes presentation and packages the same files. A selection group is one primary control: four hypotheses answer one question. Navigation/back links do not count as additional experiment controls. Each Explore screen has no more than three primary control groups.

Main navigation: Story / Design / Test / Advanced. Historical versions remain reachable inside Advanced. Original in the test flow means the generated A_uniform control, with this distinction explained near comparison and downloads. It must never silently claim to be the supplied source STL.

Metric interpretation: lower P95, maximum demand and count of ligaments >30% are better within the current model. Differences ≤0.1 percentage point in demand are labelled similar; counts compare exactly. A mix of better/worse is MIXED RESULT; at least one better and none worse is PROMISING CANDIDATE; otherwise NO CLEAR BENEFIT. Original receives CONTROL SAMPLE. Material cost is shown separately, never silently folded into a score. These labels are comparative geometric evidence, not physical validation.

Equal-volume topology mode uses Honeycomb equal-volume as its reference, not A_uniform. The existing approximately +38% feasible common budget is preserved. Test pairs use the matching baseline. Fine-tuning only enables exact existing combinations; no nearest-value snapping or new calculations.


## Naming and checks

Public labels, folders and filenames use Peça 1 / Peça 2 and Molde da Peça 1 / Molde da Peça 2. Internal IDs remain hab2 / submerged to preserve exact computational provenance. Original source files and historical URLs remain intact. New public aliases and test packages contain byte-identical STL payloads. Mold files are supplied reference tools, renamed without redesign or manufacturing validation.

The comparison ZIP contains reference and candidate STL, the corresponding mold, actual-solid comparison PNG, parameters, metrics and instructions. The four-sample ZIP uses descriptive names first; A/B/C/D are secondary experiment codes.

Equal-volume Difference displays a presentation-only Boolean subtraction of the two existing solids (candidate and equal-volume Honeycomb); it does not reuse the older A_uniform difference or change either STL. All 48 thumbnails are rendered from the actual computed mesh, without invented geometry.

Automated verification includes the real Peça 2 mixed result (P95 49.69→49.26, maximum 75.26→74.28, critical ligaments 94→100), exact fine-tune availability, reference selection, export packaging, friendly filename hashes and frozen v0.8 data. This release has no new physics or physical measurements.
